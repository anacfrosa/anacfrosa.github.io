# Personal Portfolio

Welcome to my personal portfolio website.

The color palette was selected using Color Hunt, while the design inspiration came from a combination of ideas generated with Lovable and Google Stitch.

## Design Inspiration

- Color palette: https://colorhunt.co/palette/f3f4f4853953612d532c2c2c
- UI inspiration:
  - https://www.lovable.dev
  - https://stitch.withgoogle.com

## Tech Stack

This portfolio was built using:

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS (loaded via CDN)

## Hosting

The website is hosted using GitHub Pages.

## Run Locally

You can open `index.html` directly in your browser, or run a local development server:

```bash
npx serve .
```
